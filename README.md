# BON31 会議室（プレビュー版）

山川・大原の2人と、AI2体（大原AI＝ChatGPT、Claude）が同席して会議できるアプリの試作です。

- 議題を立てて、AI同士に議論させる（往復回数は設定で変更）
- 議論の最後に「まとめ」と「決定事項の案」が出て、採用・修正・却下を選べる
- 決定事項は変更・取消の履歴が残る
- 発言をコード・資料・TODO・メモとして保管庫に保存できる

※ プレビュー版のAIの返事は見本のダミーです。データはブラウザの中だけに保存されます。
本番版ではFirebase（Hosting・Firestore・Functions）で2人が同じデータを共有し、APIで本物のAIにつなぎます。
